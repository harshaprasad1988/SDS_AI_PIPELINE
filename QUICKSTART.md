# Quick Start

### 1. Open Terminal and enter the project

```bash
cd /path/to/mds_checker
```

### 2. Run one command

```bash
./install_and_run.sh
```

### 3. Upload an MDS

In the browser:

**Upload MDS → Run Step 1 + Step 2**

### 4. Review

- OCR confidence
- Raw OCR text
- Extracted substances
- CAS numbers
- Weight % / ppm
- Components
- Suppliers
- Warnings

### 5. Export

Click **Download Step 2 extraction as CSV**.
